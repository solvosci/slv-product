Add variant values in the product description if the attribute only has
one value and if the attribute has the ‘include_variant_name’ field
checked.

**Table of contents**

.. contents::
   :local:

Usage
=====

1. Check the ‘include_variant_name’ field on Inventory>Configuration>Attributes
2. Have a product with a value in some attribute
|product_attribute|

3. Select the product, f.e doing a purchase
|purchase_product_attribute|
